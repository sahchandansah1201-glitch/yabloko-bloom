# Локальные шрифты и ранняя загрузка портрета

Опубликовано 22.10.2026 в 15:10 МСК на yaclinic.ru по разрешению владельца. Изменён только существующий snippet53 и поколение публичного HTML-кеша. Добавлены неизменяемые статические файлы; vendor, настройки шрифтов, содержимое страниц и цены не менялись.

Inter/Montserrat и Open Sans используют те же WOFF2-байты и CSS-начертания с домена клиники. 34 исходных файла скопированы без перекодирования; SHA-256 сохранены. Все 862824 байта — объём набора на сервере, не трафик одной страницы: браузер запрашивает нужные подмножества. Сохранены upstream OFL license texts. Четыре normal Cyrillic/Latin файла первого экрана объявлены preload (124176 Б суммарно). Другие языки/italic/weights доступны через исходные правила font-face.

Ajax Search Lite через штатный asl_custom_fonts больше не выводит внешний блокирующий Open Sans link; тот же шрифт подключается локально. Исправлен только известный импорт, дополнительные импорты сохраняются. В fallback CSS отзывов заменён URL общего шрифта; нативные гарнитуры вкладок отзывов не менялись.

Для doctor738 в head добавлен responsive image preload существующего attachment229. Файл около19 КБ не пережимался, srcset и размеры не менялись. На публичном изображении Elementor не применяет стандартный wp_get_attachment_image_attributes filter; фактически действующая ранняя загрузка — link preload, а не утверждение о применении img-атрибутов.

До публикации PHP hook suite: 8 проверок, исходник 5 FAIL, кандидат 0 FAIL. Дополнительная проверка конфигурации head loader также пройдена. Browser preview: 4 пары (две страницы ×390/1440), точное совпадение текстовой геометрии и фото. Первый preview обнаружил закрытую для веб-сервера новую папку assets; права исправлены до включения snippet, preview повторён. Это не изменение прав существующих каталогов.

После публикации 6 публичных загрузок (главная/Грачева ×390/768/1440): HTTP200, нет JS/HTTP-ошибок и переполнения. На390/1440 геометрия текста совпала с исходником. CSS локальные, responsive portrait preload присутствует. Полная сопоставимая серия скорости будет после второго этапа; ускорение пока не заявлено.

Объектная резервная копия вне web root, проверка исходного hash перед записью; точечный откат не требует восстановления БД. Полные снимки WordPress, защищённые backup и их адреса сюда не включены.
