## Границы доказательства

Это проверка архива, импорта БД и серверной выдачи в изолированной среде, не
браузерный тест всех функций и не реальная доставка записи. Формы не отправлялись.
Полные архивы, SQL, сертификаты, настройки доступа и HTML не опубликованы.

При недельном расписании возраст плановой копии может достигать недели. Перед
реальным откатом базы нужно отдельно сохранить новые заявки и изменения,
появившиеся после снимка; в этой задаче production-БД не восстанавливалась.
