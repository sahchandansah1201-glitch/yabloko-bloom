## Условие для этапа 2

Удаление согласовано только для перечисленных старых материалов за 7 и 19
октября. Перед удалением требуется восстановление свежей полной копии в
изолированной среде и совпадающая внешняя копия. На этом контрольном этапе
перенос и восстановление ещё выполняются, удаление не начато.

Приватные архивы, SQL, сертификаты, настройки доступа и HTML из проверки в этот
репозиторий не входят. Итоговая проверка восстановления и фактическое
освобождение места будут зафиксированы отдельно после выполнения.
