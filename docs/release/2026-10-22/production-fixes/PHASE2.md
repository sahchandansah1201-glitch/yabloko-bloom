# Виджет, сжатие JSON и результаты скорости

Опубликовано 22.10.2026 в 13:48 МСК. Существующий lazy-loader перестал включаться из-за несовпадения старого hash guard с текущим plugin bundle. Построена новая производная от текущего источника; оригинал плагина сохранён. Добавлены ready hook и защита от двойного запуска, сохранён общий URL шрифтов. Из окна успеха удалён внутренний повтор заголовка и сообщения. API и выбранные данные записи не менялись.

В production vhost к gzip_types добавлен application/json, Nginx проверен до/после и штатно перезагружен. Не добавлялся кеш доступности и персональных ответов. В template2913 убрана одна неиспользуемая пустая ACF-привязка атрибутов. Поколение существующего публичного HTML-кеша обновлено для публикации.

- Bootstrap: 220011 → 23790 Б (−89,2%). Тело после распаковки имеет тот же SHA-256 во всех шести контрольных GET: 346 услуг, 9 специалистов, 41 группа. Медиана полного GET 1660 → 1039 мс. Это не процент ускорения всей страницы.
