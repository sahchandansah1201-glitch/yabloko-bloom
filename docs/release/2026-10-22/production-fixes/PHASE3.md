# Нормализация ACF без изменения работ

Опубликовано 22.10.2026 в 14:08 МСК. Два изменённых объекта: snippet9 и Elementor template2485, плюс служебное поколение существующего публичного кеша.

Причина предупреждений подтверждена исходником: yaclinic_gallery_collage_fields добавлял сырые определения image/select в sub_fields. acf_add_local_field валидирует свою внутреннюю копию, но в массив repeater продолжали попадать невалидированные исходники без _name и multiple. Исправление — два вызова штатного acf_validate_field перед регистрацией и добавлением. В template2485 удалена одна пустая ACF-привязка атрибутов, не задававшая ключ поля.

Проверка на установленном ACF: исходный обработчик не проходил 4 проверки метаданных дочерних полей; исправленный прошёл все 4. PHP lint PASS. Vendor ACF/Elementor не изменялся.

- Все 466 строк метаданных before_after_cases опубликованных врачей и услуг сохранили исходный агрегированный digest.
- На четырёх контрольных страницах совпали порядок медиа, ссылки, превью и подписи до/после: Биоревитализация, Фотоомоложение, Грачева, Ковалев.
- 390/1440: фото1 → фото2 → видео3 → обратно → закрытие. Воспроизведение запущено штатной кнопкой Play в нативных controls; currentTime растёт, paused=false.
- После этих проверок в PHP log не добавилось новых байтов; опубликованных ACF text-тегов без ключа поля больше не найдено. Это наблюдённое окно, не гарантия отсутствия любых будущих ошибок.

Файлы медиа, медицинские подписи и назначения исполнителей не менялись. Архив исходников хранится вне web root; его адрес и полный WordPress snapshot в публичный пакет не включены. Результаты — phase3-verification.json, точный изменённый обработчик — phase3-changes.json.
