# Подготовка мобильных изображений — ещё не опубликовано

Контрольная точка задачи пяти оптимизаций `new.yaclinic.ru`, 21 октября 2026.

Проверено локально: 10 WebP-производных двух существующих PNG главной. Размеры 150, 300, 768, 1024 и 1254 px сохранены без кадрирования. Альфа-канал каждого файла побайтно совпадает с исходным. Оригиналы не изменены. `manifest.json` содержит URL, SHA-256, размеры и объём каждой пары.

Два мобильных файла 768×768: **821 864 → 59 028 байт**, уменьшение на **92,8%**. Это вес двух подготовленных файлов, не ускорение всей страницы и не подтверждение их подключения на стенде.

При публикации требуется сверить хеши существующих PNG на сервере, добавить производные без перезаписи оригиналов, заменить только `src/srcset` вложений 3338 и 3339 через фильтр WordPress. Затем проверить фактический `currentSrc`, Network, качество, ширины 360/390/768/1440 и отсутствие изменений макета. Продакшен не менять.

Применение и итоговое до/после пока заблокированы нестабильным выбором окна Termius: другая задача переключает активный терминал. Подготовленные файлы не выдаются за завершённую оптимизацию сайта.

Откат будущего подключения: отключить только фильтр производных. Восстановление базы и удаление файлов не требуются.
