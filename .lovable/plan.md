# WordPress по референсу aa7e0b9: размеры шапки, каталога и страницы услуги

Это консультация без правок проекта и без публикации. WordPress я не тестировал, значения взяты из кода референса. Медицинские тексты, цены и фото не меняются. Принятые исключения остаются: квадратные медиа, круглые стрелки галереи, целые коллажи «До/После» без увеличения, возврат к сохранённому списку.

## Общая причина DS-03 и DS-05

В референсе все размеры заданы в `rem`, а размер корневого шрифта плавающий (`src/index.css`):

```css
html { font-size: clamp(1rem, 0.958rem + 0.208vw, 1.125rem); }  /* 16 px при 320 → 18 px от 1280 */
```

На 1440 px `1rem = 18px`, поэтому значения референса — это `rem × 18`:

| Элемент | Класс в референсе | rem | 390 px (~16.1) | 1440 px (18) |
|---|---|---|---|---|
| H2 секции | `text-4xl` (line-height 2.5rem) | 2.25 | 36 / 40 (от md: 30 / 36) | 40.5 / 45 |
| H1 услуги | `text-3xl md:text-4xl lg:text-5xl` (line-height 1) | 3 | 30 | 54 |
| CTA «Записаться онлайн» | `size="xl"`: `h-14 px-10 text-lg rounded-xl` | 3.5 | 56 | 63 |
| Поля контейнера | `container padding: 1rem` | 1 | ~16 | 18 |

**Рекомендация:** в теме Elementor задать на `html` тот же `clamp()`, а размеры виджетов указывать в `rem`, а не в px. Так закрываются DS-03 и DS-05 без подбора каждого значения.

- **H2:** у WordPress 40/68 — line-height 68 px говорит о наследуемом значении 1.7 из темы. Для заголовков задать `line-height:1.111` (45/40.5).
- **CTA:** `height:3.5rem; padding:0 2.5rem; font:700 1.125rem/1 Inter; border-radius:0.75rem`.
  - В шаблоне hero у этой кнопки сейчас `rounded-full`. В референсе это перекрывает радиус `xl`, поэтому круглую форму кнопки нужно сохранить.

## 1. Шапка (`src/components/layout/Header.tsx`)

**Значения референса:**
- высота 4rem / `md` 5rem;
- логотип `h-10` / `md:h-12` с `width:auto`;
- промежуток между пунктами меню `clamp(1rem,2vw,2rem)`, размер шрифта меню `clamp(0.825rem,0.9vw,1rem)`;
- правая группа с промежутком `clamp(0.75rem,1.5vw,1.5rem)`;
- полный адрес только от `xl` (1280), ниже — «Краснодар».

**Исправление для WordPress:**
- **Логотип:** `flex:0 0 auto; height:3rem; width:auto; min-width:<ширина по пропорции>`. Логотип сжимается до 0×0 из-за `flex-shrink` и `max-width:%` у колонки Elementor. Колонке с логотипом нужно задать ширину `auto`, а не процент.
- **Пункты меню, адрес, телефон, «Запись»:** `white-space:nowrap`. Перенос «Советов экспертов» исчезнет; если ряд не помещается, это будет видно как переполнение, а не как скрытая ошибка.
- **Брейкпоинты:**
  - `< 1024` — кнопка меню;
  - `1024–1279` — «Краснодар» вместо адреса (так в референсе);
  - если на 1080 всё равно тесно — до 1260 скрыть и слово «Краснодар», оставив иконку-ссылку на «Контакты» с `aria-label` из полного адреса;
  - `≥ 1280` — полный адрес.
- **Телефон** на компьютерных ширинах всегда виден полностью.
- **Кнопки:** глаз и кнопка меню 44×44 (в референсе `size="icon"` = 40 px, для WordPress лучше 44).

## 2. Мобильный каталог, 390 px (`src/pages/ServicesHub.tsx`)

**В референсе:**
- секция hero `pt-4 pb-2`;
- H1 `text-fluid-4xl mb-1`;
- пояснение `hidden md:block`;
- поиск высотой 3rem (`h-12`);
- подсказки поиска `mt-2 gap-1.5 px-3 py-1 text-xs`;
- полоса доверия `hidden md:block`;
- блок контента `py-4`;
- вкладки `mb-8`.

**Для WordPress:**
- скрыть пояснение и полосу доверия до 768 px;
- не делать отступы больше, чем в референсе.

**Проверка:** на 390×844 верх первой карточки виден на первом экране (по оценке около 700 px), без закреплённых плашек поверх неё.

## 3. Страница услуги на мобильном

- Поля 16 px = `container padding:1rem`.
- 37.5 px у WordPress — это сумма отступов секции и колонки Elementor. У внутренней колонки должно быть `padding:0`, а у секции — `1rem`.
- **Вертикальный ритм hero** (из `ServiceHero.tsx`):
  - секция `py-12` / `md:py-20`;
  - H1 `mb-4`;
  - абзац `mb-6`;
  - чипы `gap-3 mb-8`;
  - кнопки `gap-4`;
  - колонки `gap-8` / `md:gap-12`.

## Приоритеты

1. Плавающий корневой шрифт + rem (DS-03, DS-05).
2. Шапка (п. 1).
3. Отступы на мобильном (DS-04).
4. Мобильный каталог (DS-02).
5. **DS-06** — быстрые подсказки и иконки категорий. Это часть поиска в референсе (11 подсказок, иконки во вкладках), и они влияют на поиск услуги, поэтому их стоит сделать раньше косметики.
6. **DS-07 — в последнюю очередь.**
   - Переносы H1 зависят от шрифта.
   - Градиент hero — `bg-gradient-to-b from-secondary to-background`.
   - Кнопка WhatsApp в референсе: карточка `bg-card`, `rounded-xl`, `shadow-lg`, `border`; плавающая кнопка `bg-primary`, `shadow-lg`.
   - Исправлять, только если видно визуально.

## Критерии проверки (360 / 390 / 768 / 1024 / 1080 / 1200 / 1280 / 1440)

1. Логотип не меньше 40 px по высоте на всех ширинах, пункты меню в одну строку.
2. На 1440: H2 40.5/45, H1 услуги 54, высота CTA 63 (допуск ±1 px), поля 18 px; на 390 — поля ~16 px.
3. На 390×844 первая карточка каталога видна без прокрутки.
4. Нет горизонтальной прокрутки. Цены, тексты и фото совпадают с текущими.
5. Режим для слабовидящих: шапка не переполняется, при необходимости кнопка меню появляется раньше.

## Риски

- Плавающий корневой шрифт в теме увеличит и другие виджеты, заданные в rem. Это нужно проверить на всех шаблонах.
- В зависимости от версии Elementor и темы стили сайта (global styles) могут переопределить `line-height`.
- Удобство нужно подтвердить пользовательским тестом, а сравнение с размерами референса этого не заменяет.
