# Блок «Стоимость»: цена всегда в одну строку (WordPress, рекомендация)

Это экспертная рекомендация без пользовательских тестов. Тексты, цены и кнопки не меняются, новых функций нет. Шрифт не уменьшается, и цена не обрезается многоточием.

## Причина

Цена — сжимаемый flex-элемент, и пробелы внутри «от 1700.00 ₽» — обычные. Браузер переносит её по пробелу перед «₽».

## Решение: сетка с именованными областями

Строка — это сетка `название | цена | кнопка`. Колонки цены и кнопки занимают ровно ширину содержимого и не сжимаются. Когда места не хватает, цена и кнопка переходят под название, но сама цена не разрывается.

```text
>= 640 px   [Название процедуры, переносится ......] [от 1700.00 ₽] [Записаться]
< 640 px    [Название процедуры, переносится ...................]
            [от 1700.00 ₽]                          [Записаться]
```

### CSS

```css
.price-row{
  display:grid;
  grid-template-columns:minmax(0,1fr) max-content max-content;
  grid-template-areas:"name price action";
  align-items:center;
  column-gap:16px; row-gap:12px;
  padding:16px 20px;
}
.price-row__name{grid-area:name; min-width:0; overflow-wrap:break-word; hyphens:auto;}
.price-row__price{grid-area:price; white-space:nowrap; font-variant-numeric:tabular-nums; text-align:right;}
.price-row__action{grid-area:action; min-height:44px; white-space:nowrap;}

@media (max-width:639px){
  .price-row{
    grid-template-columns:minmax(0,1fr) max-content;
    grid-template-areas:"name name" "price action";
    padding:14px 16px;
  }
  .price-row__price{text-align:left;}
}
```

### Цена в разметке

Внутри цены пробелы неразрывные: `от&nbsp;1700.00&nbsp;₽`. Вместе с `white-space:nowrap` это даёт двойную защиту, если тема или плагин сбросят стиль. Это меняет только символы пробела, а не текст цены.

### Чего не делать

- `flex-shrink` для цены, `overflow:hidden` или `text-overflow:ellipsis` на цене;
- фиксированная ширина колонки цены в px: длинные цены вида «от 12 500.00 ₽» в неё не поместятся;
- уменьшение шрифта цены через `clamp` ниже текущего размера;
- кнопка «Записаться» только с иконкой на мобильном: подпись остаётся, ширина кнопки от неё и зависит.

## Проверки

| Ширина | Ожидаемо |
|---|---|
| 1440 | Три колонки в одной строке. Цена и кнопка выровнены по правому краю у всех строк, цены друг под другом (tabular-nums) |
| 768 | Три колонки. Длинное название переносится на 2–3 строки, цена и кнопка по центру строки по вертикали |
| 390 | Название на всю ширину. Ниже цена слева и кнопка справа в одной строке |
| 360 | Как на 390. Самая длинная цена из прайса и «Записаться» помещаются в одну строку при отступах 16 px |

Для каждой ширины:
1. Ни у одной цены нет переноса: высота элемента цены равна одной строке. Можно проверить скриптом в консоли: `offsetHeight` цены ≈ `line-height`.
2. Нет горизонтальной прокрутки страницы и строки.
3. Кнопка не меньше 44 px по высоте, подпись «Записаться» видна целиком.
4. Самые длинное название и цена из прайса: название переносится, цена нет.
5. В режиме для слабовидящих (шрифт до 22 px) на 360 px цена и кнопка всё ещё помещаются в одну строку. Если нет — кнопка уходит на следующую строку (`grid-template-areas:"name" "price" "action"`), но цена не разрывается.
6. Тексты и значения цен совпадают с текущими посимвольно, кроме замены пробелов внутри цены на неразрывные.

## Риски

1. **Стили Elementor.** Elementor может переопределить `display` у виджета. Стили нужно повесить на собственный класс строки, а не на служебные классы Elementor.
2. **Разные строки в одном списке.** На 640–767 px строки с длинным названием и с коротким выглядят по-разному. Это допустимо, но стоит проверить визуально.
3. **Пробелы в WordPress.** Редактор WordPress может заменить `&nbsp;` на обычный пробел при сохранении. После публикации нужно проверить код страницы.
4. **Граница 640 px — оценка, а не замер.** Брейкпоинт нужно проверить по самой длинной цене и подписи кнопки в реальном прайсе.
