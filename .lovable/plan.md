# Возврат из услуги в каталог на то же место (WordPress, общий hero)

Это экспертная рекомендация без пользовательских тестов. Код, Elementor и публикация не меняются. Новых кнопок нет: меняется только поведение и подпись существующей ссылки «Все услуги».

## Сравнение подходов

| Подход | Плюсы | Минусы |
|---|---|---|
| 1. Только история браузера (`history.back()`) | Браузер сам возвращает на то же место в списке | При прямом входе, в новой вкладке и после перехода из поиска Google уводит с сайта. Ссылка ведёт себя непредсказуемо |
| 2. Состояние каталога в адресе + контекстная ссылка | Работает при обновлении страницы, в новой вкладке, при отправке ссылки и без хранилища. Адрес предсказуем | Позицию прокрутки адрес не хранит, она восстанавливается только в той же вкладке |
| 3. Восстановление всего из хранилища (`localStorage`) | Помнит всё | Не работает при отключённом хранилище. Состояние «протекает» между вкладками и в чужие визиты: человек приходит из рекламы и видит чужой поиск |

**Рекомендация: подход 2.** Категория и поисковый запрос хранятся в адресе каталога. Ссылка в hero несёт этот контекст. Прокрутка восстанавливается браузером при «Назад», а без него — через `sessionStorage`, причём это только улучшение, а не обязательная часть.

## Поведение

1. **Каталог пишет состояние в адрес.**
   - При выборе категории или поиске адрес меняется через `history.replaceState`, например `/services/?tab=cosmetology&q=массаж`. Запись в историю не добавляется, чтобы «Назад» не листал фильтры.
   - Пустой запрос из адреса убирается.
   - При открытии `/services/?tab=…&q=…` каталог сразу показывает эту категорию и поиск.
2. **Ссылка на услугу из каталога несёт контекст.**
   - Пример: `/services/massazh-lica/?from=cosmetology` (и `&q=…`, если поиск был).
   - Контекст передаётся только в адресе, поэтому работает и при открытии в новой вкладке.
3. **Ссылка в hero строится по контексту.**
   - Если `from` есть и это известная категория, ссылка ведёт на `/services/?tab=<from>&q=<q>#svc-<slug>`. Подпись меняется на «← Косметология», то есть на название категории из справочника, а не из адреса.
   - Если контекста нет (прямой вход, поиск Google, неизвестное значение), ссылка ведёт на `/services/`, подпись «← Все услуги».
   - Это всегда обычная ссылка `<a href>`, а не `history.back()`. Её можно открыть в новой вкладке, а адрес видно при наведении.
4. **Возврат на место в списке.**
   - На каждой карточке в каталоге есть `id="svc-<slug>"`. По хэшу каталог прокручивает к карточке и на 2 секунды мягко выделяет её рамкой `--primary`. При `prefers-reduced-motion` переход без анимации.
   - Отступ сверху учитывает закреплённую шапку: `scroll-margin-top` = высота шапки + 16 px.
   - Если найти карточку не удалось (услуга скрыта или поиск изменился), каталог остаётся вверху выбранной категории без ошибки.
5. **Кнопка «Назад» в браузере и жест «назад» на телефоне.**
   - Работают как обычно: браузер сам восстанавливает прокрутку, а каталог читает состояние из адреса.
   - `history.scrollRestoration` не переключается на `manual`.
6. **`sessionStorage`** (не обязательно):
   - хранит только точную прокрутку каталога в рамках одной вкладки;
   - если хранилище недоступно, ничего не ломается: работают адрес и хэш.

## Сценарии

| Сценарий | Результат |
|---|---|
| Косметология → «Массажи лица» → «← Косметология» | Вкладка «Косметология», прокрутка к «Массажам лица», карточка подсвечена |
| То же, но кнопка «Назад» в браузере | То же место (браузер), вкладка из адреса |
| Услуга открыта в новой вкладке | В новой вкладке ссылка «← Косметология» работает по адресу |
| Обновление страницы услуги | Контекст сохранён в адресе |
| Прямой вход или переход из Google | «← Все услуги» → `/services/` |
| Хранилище отключено | Категория, поиск и карточка восстанавливаются через адрес и хэш |
| Подменённый `from=<script>` | Неизвестное значение отбрасывается, подпись «Все услуги» |
| Телефон 360/390 | Ссылка высотой не меньше 44 px; длинное название категории переносится, а не обрезается |

## Критерии проверки

1. Все сценарии из таблицы на 360, 390, 768 и 1440 px.
2. Ссылка в hero — всегда `<a>` с настоящим `href`, без пустых ссылок и `#`.
3. Фильтры не засоряют историю: одно «Назад» из каталога уводит со страницы каталога.
4. Каноническая ссылка страницы услуги без параметров (`/services/massazh-lica/`). Параметры `from` и `q` не создают дублей в поисковиках: `rel=canonical` и запрет индексации параметров.
5. Клавиатура: после возврата фокус на подсвеченной карточке, или первый Tab ведёт к ней.
6. Аналитика: параметр `from` не ломает отчёты по страницам (сгруппировать по пути).

## Риски

1. Адреса с параметрами могут попасть в индекс поисковиков, если забыть canonical.
2. Кэширующие плагины WordPress могут отдавать каталог без учёта параметров. Чтение категории и поиска нужно делать на стороне браузера.
3. Если каталог подгружает карточки постепенно, прокрутка к хэшу сработает раньше, чем карточка появится. Нужно дождаться отрисовки.
4. Подпись «← Косметология» менее привычна, чем «Все услуги». Насколько она понятнее, нужно проверить на пользователях.
5. Длинный поисковый запрос в адресе — ограничить до 100 символов.
